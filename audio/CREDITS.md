# Halcyon audio credits

All files were downloaded from GitHub repositories, cut, looped and re-encoded with ffmpeg. Licenses were read in the repository file named in the 'License read in' column (repository commits: blanket 775f2a7672, ambie eb29bd9946, upright-piano-KW 570f6c60ed).

## Required attribution (CC BY)

- rain-patter.mp3: "Rain" by alex36917 (https://freesound.org/people/alex36917/sounds/524605/), edited by Porrumentzio for Blanket, licensed CC BY. Cut, looped and level-adjusted.
- fire-sea.mp3: "Waves" by Luftrum (https://freesound.org/people/Luftrum/sounds/48412/), edited by Porrumentzio for Blanket, licensed CC BY. Cut, looped and level-adjusted.

Note: Blanket's SOUNDS_LICENSING.md says only "CC BY" without a version. Check the version on the freesound pages (not reachable from the build container) before release.
